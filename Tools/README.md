# Tools

This folder is intentionally empty. Katalon → pytest migration is complete.

Maintain the repo directly:

- **Test steps:** edit `Testcases/<APP>/…/TC*.xlsx` (Steps sheet). See `Commons/excel_testcase/README.md`.
- **Expected data:** edit `InputFiles/<APP>/TC*.xlsx` (`TabQuery`, `StatQuery`).
- **Locators:** edit `ObjectRepository/<APP>/` YAML.

Nothing here runs at pytest time.
